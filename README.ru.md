# Оценка цены подержанного автомобиля

[English version](README.md)

Проект табличной регрессии: сравнение медианного прогноза, Ridge и CatBoost для оценки цены объявления по характеристикам подержанного автомобиля. Работа включает проверку данных, оценку моделей, анализ ошибок по ценовым группам и предсказание для CSV с помощью сохранённой модели.

**Главный результат:** CatBoost показал MAE на тесте **183 696 ₽** — примерно **на 20,5% ниже Ridge**.

## Датасет

Источник: [Used Cars на Hugging Face](https://huggingface.co/datasets/imbalet/used_cars).

В использованной версии **432 227 строк и 21 столбец**. Данные относятся к российскому автомобильному рынку. Целевая переменная — `price`, цена в рублях. Среди признаков: марка, модель, год выпуска, пробег, регион, число владельцев, характеристики двигателя, коробка передач, привод, комплектация и поколение.

Скачайте `dataset.csv` из источника и сохраните как **`cars.csv` в корне проекта**. Автоматическое скачивание не предусмотрено. Категориальные значения, например названия регионов, сохранены на языке исходного датасета.

## Обучение и оценка

1. Сохраните датасет как `cars.csv` в корне проекта.
2. Из этой же папки запустите JupyterLab:

   ```bash
   python -m jupyterlab
   ```

3. Откройте `experiment.ipynb`, выберите окружение с зависимостями и выполните все ячейки сверху вниз. Можно также использовать VS Code, выбрав это окружение как ядро ноутбука.

Обучение реализовано в ноутбуке; отдельного скрипта обучения нет.

## Методология

Данные случайно разделены на **60% для обучения, 20% для валидации и 20% для теста**, с `random_state=42`.

- **Медианный прогноз:** всем автомобилям назначается медианная цена обучающей выборки.
- **Ridge:** числовые пропуски заполняются медианами, числовые признаки стандартизируются; категориальные пропуски заменяются на `unknown`, затем применяется One-Hot Encoding. Обработка и регрессия объединены в пайплайн, обучаемый только на обучающей выборке. Параметры: `alpha=1.0`, `solver="lsqr"`.
- **CatBoost:** категориальные пропуски заменяются на `unknown`, категории передаются напрямую. Числовые пропуски обрабатываются встроенными средствами модели. Параметры: `iterations=1000`, `depth=6`, `learning_rate=0.5`, `loss_function="RMSE"`, `random_seed=42`. Лучшая итерация выбирается по MAE на валидации; задано `early_stopping_rounds=100`.

**MAE** — средняя абсолютная разница между предсказанной и указанной ценой в рублях. Чем меньше значение, тем лучше. Тестовая выборка используется для итоговой оценки и не участвует в выборе параметров.

Полных дубликатов строк не обнаружено. Строки с пропусками в признаках сохранены; в целевой цене пропусков нет. Поиск гиперпараметров не проводился.

## Результаты

| Модель | MAE на валидации, ₽ | MAE на тесте, ₽ |
|---|---:|---:|
| Медианный прогноз | 1 049 182 | 1 047 220 |
| Ridge | 228 880 | 230 988 |
| CatBoost | **182 790** | **183 696** |

В этом эксперименте CatBoost оказался лучше Ridge и выбран для команды предсказания. Лучшее значение на валидации достигнуто на последней итерации; ранняя остановка не сработала.

### Ошибки по ценовым группам на валидации

Группы определены по терцилям цены обучающей выборки. Границы — **739 500 ₽** и **1 676 000 ₽**.

| Группа | Автомобилей | MAE медианы, ₽ | MAE Ridge, ₽ | MAE CatBoost, ₽ |
|---|---:|---:|---:|---:|
| Дешёвые: ≤ 739 500 | 28 837 | 708 497 | 139 269 | **82 843** |
| Средние: > 739 500 и ≤ 1 676 000 | 28 641 | 232 227 | 152 258 | **135 881** |
| Дорогие: > 1 676 000 | 28 967 | 2 196 098 | 393 848 | **328 669** |

CatBoost показал меньшую MAE во всех группах. Более высокая абсолютная ошибка на дорогих автомобилях сама по себе не доказывает более высокую относительную ошибку.

## Предсказание для CSV

После выполнения ноутбука запустите из корня проекта:

```bash
python predict.py --input cars_example.csv --output predictions.csv
```

Для собственных данных замените путь к входному файлу:

```bash
python predict.py --input new_cars.csv --output predictions.csv
```

Рядом со скриптом должна находиться папка `models` с файлами `catboost.cbm` и `metadata.json`. Папка модели определяется относительно `predict.py`; пути входного и выходного CSV — относительно текущей папки терминала, если не указаны абсолютные пути.

### Формат входных данных

Каждая строка описывает один автомобиль. CSV должен содержать все 20 признаков обучения:

```text
owners, year, region, mileage, mark, model, complectation,
steering_wheel, gear_type, engine, transmission, power,
displacement, characteristics, color, body_type_type,
body_type_name, super_gen_name, super_gen_year_from, super_gen_year_to
```

Единицы измерения и обозначения категорий должны соответствовать исходному датасету. Числовые столбцы должны содержать числа или пропуски. Столбец `price` необязателен и для предсказания не используется. Скрипт проверяет наличие столбцов, устанавливает сохранённый порядок признаков и обрабатывает категории.

### Результат

Выходной CSV сохраняет входные столбцы и добавляет **`predicted_price`** — предсказанную цену в рублях. Существующий столбец с таким названием заменяется. Если выходной файл по указанному пути уже существует, он перезаписывается.

В ноутбуке есть необязательная проверка совпадения предсказаний скрипта и модели в памяти на десяти автомобилях. Выполняйте её после того, как команда создаст выходной CSV.

## Ограничения

- Цены относятся к объявлениям, а не к подтверждённым суммам сделок.
- Дата сбора описана недостаточно подробно; эксперимент не подтверждает точность для актуальных рыночных цен.
- Случайное разбиение не проверяет качество на будущих данных. Временное разбиение не проводилось.
- Проверка полных дубликатов не исключает повторных объявлений с изменёнными характеристиками.
- Сравниваются конкретные настройки без поиска гиперпараметров; универсальное преимущество алгоритма не доказывается.
- Версии зависимостей закреплены, но воспроизведение в чистом окружении не проверялось.

Это учебный проект оценки цены, а не развёрнутый сервис автомобильной оценки.
